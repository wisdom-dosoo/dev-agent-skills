# Expo playbook

## New project
```bash
npx create-expo-app@latest my-app
cd my-app
npx expo start
```
Check `package.json` afterwards: confirm the `expo` version against `current-state.md`.

## Upgrading an SDK
```bash
npx expo install expo@latest          # or expo@^NN for a specific SDK
npx expo install --fix                # align all Expo-managed deps
npx expo-doctor                       # must be clean before building
```
Then read that SDK's changelog at expo.dev/changelog for breaking changes. Upgrade one SDK at a time; skipping versions multiplies breakage. Delete stale `ios/` and `android/` only in CNG projects (they are regenerated by `npx expo prebuild --clean`).

## Development build vs Expo Go
- Expo Go: fine for pure-JS and Expo SDK modules.
- Development build: required once you add a library with custom native code.
```bash
npx expo install expo-dev-client
eas build --profile development --platform all
```

## Config, not hand edits
- App identity, permissions, plugins: `app.config.ts` (dynamic) or `app.json`.
- Android build knobs (targetSdk, compileSdk, minSdk): `expo-build-properties` plugin.
- iOS usage strings: `ios.infoPlist` in app config or the library's plugin options.

## EAS
```bash
eas build --profile production --platform all
eas submit --platform ios       # App Store Connect
eas submit --platform android   # Google Play
eas update --branch production --message "fix: ..."
```
- Keep build profiles in `eas.json`: `development`, `preview` (internal distribution), `production`.
- Set a `runtimeVersion` policy so an OTA update can never land on an incompatible native build.
- Secrets used at build time: `eas secret:create` / EAS dashboard. Never `EXPO_PUBLIC_` for secrets.

## Common failures
| Symptom | First check |
|---|---|
| ERESOLVE on install after upgrade | A library's peer cap excludes the new expo-* major |
| "Native module X not found" in Expo Go | Needs a development build |
| Crash only in release builds | Reanimated/worklets versions vs SDK; run `npx expo-doctor`; Hermes config |
| Metro cache weirdness | `npx expo start --clear` |
| OTA update crashes app | Native dependency changed without new runtimeVersion |
